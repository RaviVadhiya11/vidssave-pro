How it works

Three simple steps for content you own or have permission to download.

STEP 01

Copy a media link

Copy the public link from the original platform or source website.

STEP 02

Paste it above. This starter version checks the URL format only.

Continue through the source's own download option or an approved integration.

Responsible use: Download only media you created, own, or have permission to save. This site does not bypass DRM, private-account settings, paywalls, login requirements, or other access controls. Respect copyright and each platform's terms.

Frequently asked questions

Does this version download videos already?

No. This first version is the responsive frontend and URL-format checker. Actual downloading requires a lawful, supported backend or official source integration.

Why does a platform show as supported?

The names indicate planned source support, not a guarantee of live compatibility. Download options will appear only after an integration is implemented and tested.

Can I save private or restricted videos?

No. The service will not bypass login restrictions, DRM, private content controls or other technical protections.

Is it free?

The static website can be hosted on GitHub Pages at no cost within GitHub's current limits. A backend, processing provider or media API may have usage limits or charges.
